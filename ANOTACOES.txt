---

Passo 1: Criar o volume de dados do Portainer

Este comando garante que suas configurações fiquem salvas caso o container seja reiniciado ou atualizado:

docker volume create portainer_data

---

Passo 2: Rodar o container do Portainer


Cole o comando abaixo no terminal para baixar e iniciar a interface gráfica:

docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest

---

Passo 3: Acessar a Interface Gráfica

1. Abra o navegador de sua preferência.
2. Acesse: https://localhost:9443
3. Aceite o aviso de certificado autoassinado (normal em uso local).
4. Crie sua senha de administrador (mínimo 12 caracteres).
5. Selecione "Get Started" para conectar o Portainer ao Docker local.
